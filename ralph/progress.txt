## Codebase Patterns
- Notebook metadata stored in `notebooks_meta.json` via `_load_meta()` / `_save_meta()` helpers in `backend/app/routers/notebooks.py`
- Use `from __future__ import annotations` in schemas when adding forward-referencing types
- Always use `.get("key", default)` when reading optional fields from JSON metadata to remain backward-compatible with older records
- Frontend TypeScript types mirror backend Pydantic schemas in `frontend/src/types/index.ts`
- Python import test: `python -c "from app.models.schemas import NotebookResponse, ChatMessage"` from the `backend/` directory
- TypeScript check: `npx tsc --noEmit` from the `frontend/` directory (with `npm install` first if node_modules missing)
- File download from API: use raw `fetch()` + `res.blob()` (NOT `request<T>()` which calls `res.json()`); parse Content-Disposition header for filename; trigger download via URL.createObjectURL → anchor.click → URL.revokeObjectURL
